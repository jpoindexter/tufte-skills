# 11 freshly-written skills carried ~55 wrong claims

**Context:** Rounds 1–2 extracted 11 new skills from the Tufte books, each written by an agent that had just read the source. A third round read them back against the books.
**Dead ends:** Treating "the agent read the book while writing" as verification. Signal: ~55 wrong claims survived — an inverted framing (a passage Tufte admires, written up as a failure case), a quote attributed to Tufte that was Fitzkee's, two conflated staircase cases, a fabricated quotation mark, and one 2-sentence verbatim run.
**What worked:** A separate pass whose only job was falsification — per skill, enumerate every checkable claim (page cite, number, quote, attribution), read the source pages, and mark each CONFIRMED / WRONG / UNVERIFIABLE, with a standing instruction that unverifiable precision must be softened or deleted.
**Why:** Writing optimizes for a coherent narrative and silently smooths detail; verification optimizes for mismatch. The same agent cannot do both on one pass, because the claim and the memory of writing it are the same object.
**Rule:** After extracting content from a source, run a separate pass that re-reads the source and marks every claim CONFIRMED / WRONG / UNVERIFIABLE before the content is trusted.

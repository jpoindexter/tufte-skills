# A second full extraction pass over "exhausted" books yielded 8 skills

**Context:** After a page-by-page audit-and-fix pass, the books looked mined out; a re-run was requested.
**Dead ends:** Assuming the first pass's "new-skill candidates: none/optional" verdicts were final. Signal: round 2 built 8 skills from material round 1 had explicitly parked or dismissed as optional, and reversed one of round 1's own corrections (a claim marked unverifiable was verbatim on p.53).
**What worked:** Giving each round-2 agent a different mission from round 1 — build the parked candidates, sweep only for residue, with an explicit honest-thinness exit ("say thin, don't pad"). Two agents used the exit (EI, and visual-index nearly); four built real skills.
**Why:** Audit-mode attention (verify what exists) and extraction-mode attention (find what doesn't) surface different material from the same pages; the thinness exit keeps the second pass honest instead of padding to justify itself.
**Rule:** When re-mining a source, change the mission (audit vs extract), pre-assign the parked candidates, and give every agent an explicit permission to return "nothing found."
